# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub, using [Report a vulnerability](https://github.com/vince844/kondomanager-free/security/advisories/new). If you cannot use GitHub, write to kondomanager@pm.me.

Include the version or commit you tested, the steps to reproduce the problem and what an attacker can achieve with it.

We will reply as soon as we can, keep you informed while we work on a fix, and credit you in the security advisory unless you prefer otherwise.

## Supported versions

Security fixes are included in the next release; we do not publish patches for older versions. Please check that the problem is still present in the latest release or in the current pre-release before reporting it.

## Contributing a fix

If you want to write the fix yourself, we will add you to a private security advisory with a temporary private fork, so the fix is not public before the release. External contributions require the [Contributor License Agreement](https://cla-assistant.io/vince844/kondomanager-free), which you can sign from that link at any time.
